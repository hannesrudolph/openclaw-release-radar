Release stability

Automatically tracks GitHub issues for each release and tells you which one to install right now. Compares each release's bug-load to what's typical for this project. Source: openclaw/openclaw

Why not just install an older release that looks quiet? Old releases look quiet because their users moved on, not because they're safe — they may still carry unpatched issues that newer releases fix silently. This view never points you at versions older than the recommended one.

Raw 0–10 scores (legacy, retained for API consumers)

Each release accumulates every still-open bug from project history; latest releases have the longest debt and structurally score lowest. For "should I install this?" the recommendation above is the answer.
