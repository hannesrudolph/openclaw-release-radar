What this assessment means

Global assessment is an ordinal 0–10 policy/stability ranking, not a probability or percentage. Higher values mean stronger evidence under the current audit and recommendation policy; the top of the scale does not imply certainty or an absence of issues.

It combines install gates such as medium-or-higher security advisories, wait/hotfix status, release age, beta shake-out, breaking changes, and the balance of serious issues opened vs fixed during the release window.

My setup filters affected areas and related issue evidence. It never changes the audited assessment or the globally recommended update target.

The assessment is a triage aid, not a guarantee. Expand a release to see the evidence issues behind the number.
